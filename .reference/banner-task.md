## **VELOOP Rewards – Frontend Development Task Assignment** 

## **Task 0G – Rewards, Engagements Utility Banner/Card Redesign** 

#### **Assigned Components** 

For this task, you are required to completely redesign and redevelop the following five VELOOP Rewards banners/cards: 

### 1. **Leaderboard Banner** 

2. **Watch Ad s Earn Banner** 

### 3. **Contact Us Banner** 

### 4. **Follow s Earn Banner** 

### 5. **Daily Bonus Banner** 

These components should follow the same design standards established for the previous banner assignment while having their own visual identity and purpose. 

#### **1. Project Objective** 

The objective of this task is to create **premium, modern, interactive, trustworthy, and highly engaging banners/cards** that fit naturally into the VELOOP Rewards platform. 

Each banner should immediately communicate: 

- What the feature is 

- What benefit it provides 

- What the user can do 

- Why the user should interact with it 

The final UI should feel like a combination of: 

#### **Modern Fintech + Rewards Platform + Gamification + Premium SaaS** 

The design should encourage users to return to the platform and interact with different features. 

#### **2. Important Global Banner Standards** 

These requirements apply to **all five banners** . 

They should also be treated as the standard for future VELOOP Rewards banner/card assignments unless a future task explicitly specifies otherwise. 

#### **3. Body Background** 

The application body background must remain: 

#161827 

Every banner must complement this background. 

The card should appear visually separated from the body without looking disconnected from the platform. 

#### **4. Width Requirement** 

Every banner/card must use: 

#### **100% available width** 

The banner should adapt to the available width of its parent/container on every screen size. 

Do not use a small fixed-width card on desktop. 

The banner should feel like a major feature section rather than a tiny promotional box. 

### **5. Height Requirements** 

Follow these height ranges. 

### **Laptop / Desktop** 

**Minimum:** 410px 

**Maximum:** 450px 

### **Tablet** 

**Minimum:** 380px 

**Maximum:** 540px 

### **Mobile** 

**Minimum:** 330px 

**Maximum:** 520px 

### **Important** 

The height should be responsive. 

Do not blindly use one fixed height for every device. 

The content, illustration, typography, and CTA should adapt naturally while staying within the specified range.
